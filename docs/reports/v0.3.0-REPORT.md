# Report — v0.3.0
Ημερομηνία: 2026-10-30. Branch: `ai/v0.3.0`.

## Τι έγινε
- Διορθώθηκε το migration config v3→v4 ώστε κενή λίστα `commands.items` να διατηρείται.
- Ενημερώθηκαν τα tests για `CONFIG_VERSION == 4` και προστέθηκε skip όταν λείπει `rapidfuzz`.
- Στο UI εντολών προστέθηκαν «Προσθήκη εντολής» και «Διαγραφή επιλεγμένης».
- Φράσεις και ορίσματα χρησιμοποιούν διαχωριστή `;`.
- Προστέθηκε tooltip για άμεση εκτέλεση και προειδοποίηση όταν λείπει `rapidfuzz`.
- Ενημερώθηκαν README, CODE-MAP, VERSION, CHANGELOG, TESTS, HANDOFF και NEXT-CHAT-PROMPT.

## Τι να δοκιμάσω
1. `pytest tests/test_config_v3.py tests/test_commands.py -q`
2. `pytest -q`
3. ⚙ → Φωνητικές εντολές: προσθήκη, διαγραφή, `;` σε φράσεις/ενέργειες, tooltip «Άμεση».
4. Χωρίς `rapidfuzz`: εμφανίζεται προειδοποίηση και τα σχετικά tests κάνουν skip.
5. Config με `commands.items: []`: μετά την εκκίνηση παραμένει κενό.

## Γνωστά θέματα
- Χωρίς `rapidfuzz` δεν εκτελείται ταύτιση εντολών.
- Τα αποτελέσματα pytest και τα χειροκίνητα ✅ καταγράφονται από τον χρήστη στα Windows.
