# Αναφορά v0.2.1 — Θωράκιση release.ps1
Ημερομηνία: 2026-10-30. Branch: ai/v0.2.1. Βάση: main `1d2a0d5d70fe74e095d95ba9309c707d4cf6b781`.

## Τι έγινε
- Το `scripts/release.ps1` τώρα απαιτεί καθαρό main, ίδιο SHA με `github/main`, και αποτυγχάνει σε untracked αρχεία.
- Τα απαιτούμενα remotes ορίζονται στο `release.required_remotes` του config.json (default `github`). Το Gitea/`origin` δεν απαιτείται.
- Το tag είναι idempotent: ίδιο commit = συνέχεια, άλλο commit = αποτυχία.
- Μετά το push επαληθεύεται ότι το tag υπάρχει στο κάθε remote. Αποτυχία δίνει μη μηδενικό exit code.
- Το zip ελέγχεται ότι δημιουργήθηκε πριν συνεχίσει το script.

## Τι να δοκιμάσεις
1. Merge του PR και `git pull github main`.
2. `./scripts/release.ps1 -Message "θωράκιση release"` χωρίς bump.
3. Έλεγξε ότι δημιουργήθηκε `dist/tooldock-v0.2.1.zip` και ότι το tag `v0.2.1` εμφανίζεται στο GitHub.
4. Δοκίμασε αποτυχία: τρέξε το script από branch ≠ main ή με untracked αρχείο — πρέπει να σταματήσει με σφάλμα.
