# REPORT v0.2.0 — Υπαγόρευση & πάροχοι STT

## Τι έγινε
- Νέο plugin `dictation`: κουμπί 🎤 στη λωρίδα και στο compact/full· ένα πάτημα ξεκινά, δεύτερο σταματά χειροκίνητα.
- Ηχογράφηση με `sounddevice` (16 kHz mono, int16) και αυτόματο στοπ σε σιωπή (RMS) ή timeout χωρίς ομιλία.
- Νέο πακέτο `speech/`: κοινό interface `Provider.transcribe(audio, lang)`, `SpeechService` με λίστα προτεραιότητας και fallback, `SilenceDetector`, `Recorder`.
- Πάροχοι: Google Web Speech (`SpeechRecognition`) και faster-whisper τοπικά (lazy φόρτωση, μοντέλο `small`/cpu/int8, κατέβασμα στην πρώτη χρήση).
- Γλώσσες el/en με κουμπί εναλλαγής· αντιστοίχιση κωδικών ανά πάροχο (`el-GR`/`en-US` για Google, `el`/`en` για Whisper).
- Το κείμενο μπαίνει στο πλαίσιο υπαγόρευσης (επεξεργάσιμο)· η γραμμή κατάστασης δείχνει Ηχογράφηση… / Αναγνώριση… (πάροχος) / αποτέλεσμα ή σφάλμα.
- config v3: ενότητα `speech.*`, plugin `dictation`, κουμπί `mic` στη λωρίδα (αυτόματο migration από v2, χωρίς διπλότυπα).
- Προαιρετικές εξαρτήσεις σε `requirements-speech.txt`· χωρίς αυτές η εφαρμογή ξεκινά και το κουμπί δείχνει οδηγία.

- Πρώτη χρήση Whisper: κατέβασμα μοντέλου (~0,5–1,5 GB) και αργή εκκίνηση.
- Google Web Speech: online/ανεπίσημο· χωρίς internet → fallback στον Whisper.
- Το hotkey υπαγόρευσης πάει στο S4 (απόφαση Δ21).
