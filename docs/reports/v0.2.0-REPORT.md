# REPORT v0.2.0 — S2 υπαγόρευση και σταθεροποίηση
Ημερομηνία ενημέρωσης: 2026-10-30. Branch ai/v0.2.0, PR #1. Κατάσταση: τελικός επανέλεγχος, όχι release.

## Τι έγινε
Ηχογράφηση sounddevice, κοινό interface STT, Google Web Speech και τοπικό faster-whisper, γλώσσες el/en, status και fallback. Προαιρετικές εξαρτήσεις στο requirements-speech.txt και lazy μοντέλο Whisper. Config v3 με speech και migration κουμπιού mic.
Διορθώθηκαν worker.finished, διπλό κουμπί, αμφίσημη επιλογή μικροφώνου (όνομα + host API), buttons→compact και αποσύνδεση υπαγόρευσης από το OK. Υπάρχει πλέον κοινό πεδίο κειμένου/σημειώσεων.
Τελευταίο patch: η περιοχή χειριστηρίων μικροφώνου δεν καταλαμβάνει επιπλέον ύψος όταν notes=true. Το fallback πεδίο όταν notes=false παραμένει επεκτάσιμο.
